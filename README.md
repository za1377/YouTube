# YouTube Homepage Clone 🎬
A simple React + TypeScript project built to practice React Context, Styled-Components, and TypeScript.

## ✨ Features
- Sidebar with navigation menu
- Video list with thumbnails and titles
- Dark/Light theme toggle (using React Context)
- Language toggle (Persian/English)
- Component-based structure with Styled-Components

## 🛠 Tech Stack
- **React** + **TypeScript**
- **Styled-Components** for styling
- **React Context** for global state (theme + language)
- **Vite** for fast development

## 🎯 What I Learned
This project was built as a practice to master:
- **React Context API** for managing global state (theme and language)
- **Styled-Components** for dynamic and scoped styling
- **TypeScript** for type-safe components and props
- **Component-based architecture**
